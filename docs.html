SignalForge Pro · v2.4

Introduction

SignalForge Pro is a complete template kit for building a creator-intelligence SaaS. It includes 14 HTML pages, 3 themes, full app shell, command palette, animations and liquid glass UI.

Installation

No build step required. Just open index.html in a browser, or deploy the folder to any static host.

# Local preview
python3 -m http.server 8000
# Then open http://localhost:8000

Theming

Three themes ship: theme-dark, theme-midnight, theme-noir. The switcher is in the bottom-right corner and persists in localStorage.

To add your own, append a body class in styles.css:

body.theme-yourname{
  --bg-0:#0a0014;
  --bg-1:#10001f;
}

Demo data

All dashboard pages read from assets/data.json (or data.js fallback for offline). Edit values in the JSON to change trends, opportunities and hook templates instantly.

Adding pages

Copy any existing dashboard page (e.g. radar.html), keep the sidebar block, replace the .app-body content.

Deployment

Drop the folder on Vercel, Netlify, Cloudflare Pages or GitHub Pages. Zero config required.
