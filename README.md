# SignalForge Pro

A premium template kit for building a creator intelligence SaaS.
Built with pure HTML, CSS, and vanilla JavaScript. Zero frameworks.

## What's inside
- 14 fully-built HTML pages (landing, dashboard, radar, hooks, analyzer, explorer, opportunity engine, settings, pricing, auth, 404, docs, changelog)
- 3 switchable color themes (Dark / Midnight / Noir)
- iOS 26-inspired liquid glass UI
- Functional command palette (Cmd/Ctrl + K)
- Live demo feed, heatmap, charts, animations
- JSON-driven demo data — edit and ship in minutes
- Mobile-responsive app shell with sidebar
- Magnetic buttons, 3D parallax hero, reveal-on-scroll

## Quick start
```bash
python3 -m http.server 8000
# open http://localhost:8000
```

Or open `index.html` directly in any modern browser.
